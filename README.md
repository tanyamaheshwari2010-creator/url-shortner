# URL Shortener

A simple URL shortening web application built with Node.js, Express.js, and MongoDB.

## Features

- Create short URLs from long URLs
- Redirect users using the generated short URL
- Store URL data in MongoDB
- REST API based backend

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
